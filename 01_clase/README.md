## Fuente de datasets recomendados

| Fuente | Descripción | Ideal para | Enlace |
|--------|-------------|------------|--------|
| **Kaggle Datasets** | Plataforma muy popular con vasta colección de datasets subidos por la comunidad y organizaciones, muchos ya limpios y listos para usar. Filtros por tarea (clasificación, regresión), popularidad, etc. | Encontrar datasets de competiciones pasadas (bien preparados) y gran variedad de temas. | [Kaggle](https://www.kaggle.com/datasets) |
| **UCI Machine Learning Repository** | Colección clásica de bases de datos usadas por la comunidad de ML por años. Muchos datasets académicos o "de juguete", con buena documentación de variables. | Datasets más pequeños y bien establecidos, perfectos para practicar algoritmos de clasificación y regresión. | [UCI ML Repository](https://archive.ics.uci.edu/ml/index.php) |
| **Google Dataset Search** | Motor de búsqueda específico para datasets. Indexa miles de repositorios (gubernamentales, académicos, etc.). | Búsqueda amplia cuando se tiene un tema específico en mente y se quiere ver qué hay disponible en diferentes fuentes. | [Google Dataset Search](https://datasetsearch.research.google.com/) |
| **Data.world** | Plataforma colaborativa para datos. Permite encontrar, compartir y trabajar con datos públicos. Incluye herramientas de exploración. | Encontrar datasets con enfoque comunitario, a menudo con discusiones o análisis ya iniciados. | [Data.world](https://data.world/) |
| **Awesome Public Datasets (GitHub)** | Lista curada en GitHub de datasets públicos de alta calidad, organizados por tema (agricultura, biología, economía, educación, etc.). | Explorar datasets por áreas de interés específicas. | [Awesome Public Datasets](https://github.com/awesomedata/awesome-public-datasets) |
| **Portales de Datos Abiertos Gubernamentales** | Datos publicados por gobiernos (nacionales, regionales, locales) sobre demografía, economía, salud, transporte, etc. Suelen requerir más limpieza. | Proyectos con enfoque cívico o análisis de datos del mundo real de una región específica. | Ejemplos: [Data.gov (EE.UU.)](https://www.data.gov/), [Datos UE](https://data.europa.eu/es), [Datos Argentina](https://datos.gob.ar/), [Datos España](https://datos.gob.es/es), [Datos México](https://datos.gob.mx/) |
| **FiveThirtyEight** | Sitio de periodismo de datos que publica los datasets utilizados en sus artículos. | Encontrar datasets interesantes y actuales, relacionados con política, deportes y cultura popular, con el contexto del artículo original. | [FiveThirtyEight Data](https://github.com/fivethirtyeight/data) |
